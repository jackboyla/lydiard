# Primary coaching principles

Replace this file's content with your own coaching reference, then save it as
`wisdom/scullion-principles.md`. That filename is gitignored, so your own notes stay private.

The coach reads this text as principles, not prescriptions. Write it the way you would brief a
training partner: durable ideas first, worked examples second, and a clear note about what applies
only to elite athletes.

## 1. The system in one page

Summarize your approach as a short ordered list. For example:

1. Build consistency before intensity.
2. Accumulate an aerobic base you can sustain.
3. Keep threshold work repeatable rather than maximal.
4. Add race-specific sharpening only once the base holds.

## 2. Sessions

Describe the sessions you actually use, with the intent behind each one rather than a fixed
prescription.

## 3. Recovery and constraints

Note what should make the plan back off: illness, poor sleep, persistent soreness, or life load.
